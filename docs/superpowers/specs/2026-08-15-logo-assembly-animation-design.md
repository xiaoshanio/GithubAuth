# GithubAuth Logo 组装动画测试设计

日期：2026-08-15

## 1. 目标

创建一个独立的高清动画测试页，用现有 GithubAuth Logo 表现以下组装过程：

1. 四个完整方框分别从左、右、上、下移动到中心。
2. 四个方框在中心形成轻微错位的四层结构，每层边缘均可见。
3. 带黑色外描边的紫色打开状态锁块从上方落到中心。
4. 锁梁下压并闭合。
5. 整个锁块轻微缩小并向内下压，形成嵌入并锁定的效果。
6. 画面无缝切换到完整原始 Logo，四层方框继续保留，停留后循环播放。

## 2. 范围边界

- 测试文件放在 `prototypes/logo-animation-gsap.html`。
- 不修改正式 React 页面、路由、组件或 Tauri 功能。
- 不读取或修改应用数据。
- 不在本轮接入启动页、初始化页或登录页。
- 只制作一个已确认的视觉方向，不增加主题、颜色或动画方案选择器。

## 3. 技术方案

测试页使用 HTML、CSS、内联 SVG 和 GSAP 时间轴。

- 使用现有 `client/public/assets/github-vault-logo_fdf70cb3.png` 作为唯一 Logo 素材。
- 通过 SVG `clipPath` 将原图分成锁体和锁梁，保留原图材质和黑色描边。
- 四个完整方框使用 CSS 图层，从四个方向独立进入并在中心形成错位叠层。
- GSAP 负责所有图层的位移、旋转、透明度、停留和循环顺序。
- 最终帧直接显示完整原始 Logo，消除分层遮罩可能产生的边缘误差。
- 测试页通过 CDN 加载 GSAP，不向正式应用的依赖清单添加包。

## 4. 视觉结构

页面使用中性深灰背景，动画保持在稳定的正方形舞台中并自适应窗口尺寸。原始素材为 1920 x 1920，显示时保持长宽比，不进行低分辨率重采样。

从后向前的图层顺序为：

1. 从左进入的紫色半透明方框。
2. 从右进入的深色填充方框。
3. 从上进入的石墨色描边方框。
4. 从下进入的暗紫色描边方框。
5. 紫色锁体与可独立运动的锁梁。
6. 最终完整 Logo。

四个方框使用当前 `VaultMark` 的紫色和中性深灰材料，不增加与 Logo 无关的高饱和颜色。四框在最终画面中保留，并通过轻微的位置和旋转差异露出各层边缘。锁始终使用当前 Logo 的紫色、材质、高光和黑色描边，不使用通用扁平锁图标。

## 5. 时间轴

主动画采用沉稳、机械式缓动，不使用弹跳效果：

- `0.00-1.20s`：四个完整方框依次从左、右、上、下进入。
- `1.30-2.10s`：带黑色外描边的紫色开锁块从上方落下。
- `2.10-2.50s`：锁梁旋转并下压闭合。
- `2.50-2.80s`：整个锁块轻微缩小并向中心下压嵌入。
- `2.80-3.05s`：分层锁块交叉淡化为完整原始 Logo。
- `3.05-4.25s`：保留最终帧和四层方框，然后重新循环。

测试页提供重新播放按钮。重新播放会从时间轴起点开始，不创建叠加的并行时间轴。

## 6. 响应式与可访问性

- 动画舞台使用固定正方形比例和响应式最大尺寸，桌面与手机视口均完整显示。
- 控件不能覆盖 Logo 或改变舞台尺寸。
- `prefers-reduced-motion: reduce` 生效时不自动播放，只显示最终 Logo；用户仍可主动点击重新播放。
- 动画图层不作为独立可读内容暴露给辅助技术，最终 Logo 使用简洁替代文本。
- 不使用随视口宽度变化的字体大小，按钮文字在窄屏完整显示。

## 7. 失败处理

- Logo 素材加载失败时显示明确的素材加载错误，不播放空白动画。
- GSAP CDN 加载失败时显示静态完整 Logo，并提示动画库未加载。
- SVG 遮罩不受支持时跳过分层过程并显示完整 Logo。
- 页面运行时不记录敏感数据，也不发送除 GSAP CDN 请求之外的网络请求。

## 8. 验证

完成后进行以下检查：

- 在桌面视口检查四个方框分别从左、右、上、下进入，以及开锁下落、闭锁和嵌入顺序。
- 在手机视口检查舞台、Logo 和重播按钮无裁切或重叠。
- 截取动画中段和最终帧，确认画布非空且最终帧与原始 Logo 一致。
- 检查四个背景框在最终帧均可辨认且仍可见。
- 检查连续重新播放不会加速、重影或导致布局位移。
- 模拟 GSAP 加载失败，确认静态 Logo 回退有效。
- 模拟减少动态效果，确认不会自动播放。

## 9. 完成标准

- 独立测试页可通过现有开发服务器打开。
- 动画严格遵循已确认的四框汇合、锁块落下、闭锁、嵌入和最终定格顺序。
- 四个完整背景框分别从左、右、上、下进入，并保留在 Logo 后方。
- 打开的紫色锁块从上方进入，随后清楚地完成闭锁和向内嵌入动作。
- 最终画面使用完整 1920 x 1920 原始 Logo。
- 测试文件之外的正式应用代码和运行行为不发生变化。
