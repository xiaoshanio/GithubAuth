# GithubAuth 解锁过渡动画接入设计

日期：2026-08-16

## 1. 目标

在用户成功完成密码登录、2FA 登录或首次初始化后，播放一次已经确认的四框 Logo 组装动画。动画完成后保持完整 Logo，随后自动进入账户主界面。

每次成功进入保管库只播放一轮。用户锁定保管库并再次成功登录时，视为新的解锁会话，再播放一轮。

## 2. 范围

本次包含以下成功入口：

1. 使用主密码解锁现有保管库。
2. 使用 6 位 2FA 验证码快速解锁。
3. 首次初始化时选择仅使用密码。
4. 首次初始化时完成 2FA 绑定。

本次不修改 Rust 认证、加密、TOTP 或备份逻辑，不在应用启动、普通页面切换或设置变更时播放动画。

## 3. 状态架构

`Home` 继续作为认证页和主界面的状态边界，并新增一个待完成解锁状态：

```text
AuthScreen
  -> onUnlocked(view)
  -> Home.pendingUnlock = view
  -> UnlockTransition 播放一轮
  -> onComplete()
  -> Home 将 pendingUnlock 写入 vault
  -> 渲染账户主界面
```

`acceptUnlock` 不再立即设置 `vault`，而是暂存完整 `UnlockView`。当存在 `pendingUnlock` 时，`Home` 渲染全屏 `UnlockTransition`，不再显示认证表单。

完成回调负责一次性提交以下状态：

- `vault`
- `quickUnlockEnabled`
- `vaultStatus`
- 清空 `pendingUnlock`

该边界让密码、2FA 和两种初始化路径共享同一动画入口，不需要在 `AuthScreen` 中复制动画逻辑。

## 4. 动画组件

新增 `client/src/components/UnlockTransition.tsx`。组件只负责视觉过渡，接口保持最小：

```text
UnlockTransition
  onComplete: () => void
```

组件使用本地安装的 GSAP、现有 1920 x 1920 Logo 素材和内联 SVG 遮罩。正式应用不使用 CDN，也不包含测试页工具栏或重播按钮。

动画顺序：

1. 四个完整方框分别从左、右、上、下进入中心。
2. 四框形成轻微错位的四层结构。
3. 带黑色外描边的紫色开锁块从上方落下。
4. 锁梁旋转并下压闭合。
5. 整个锁块轻微缩小并向中心下压嵌入。
6. 画面切换为完整原始 Logo，四层方框继续保留。
7. 完成帧保持约 1.2 秒后调用 `onComplete`。

时间轴不循环，不提供手动重播。

## 5. 安全与故障处理

- 动画开始前 Rust 已完成认证；动画不接触密码、2FA 验证码或密钥。
- `pendingUnlock` 仅保存已经返回给 React 的 `UnlockView`，不新增持久化或日志。
- 完成回调使用一次性保护，避免时间轴完成和故障兜底重复提交状态。
- Logo 素材加载失败、GSAP 初始化失败或动画抛出异常时立即调用完成回调，不能阻塞已成功的解锁。
- 组件卸载时销毁 GSAP 时间轴和媒体查询上下文。
- 用户在动画期间关闭窗口时不执行额外保存或认证请求。

## 6. 性能与可访问性

- GSAP 作为本地依赖打包到应用，不发送 CDN 请求。
- 动画只更新 `transform`、透明度和少量静态阴影，不动画宽高、边距或定位属性。
- `will-change` 只在动画组件存在期间生效；组件结束后整体卸载。
- 时间轴仅播放一次，页面隐藏或组件卸载时立即停止。
- `prefers-reduced-motion: reduce` 生效时跳过运动，显示完整 Logo 短暂停留后进入主界面。
- 动画舞台保持稳定正方形比例，在桌面与手机视口中完整显示且不产生滚动条。
- 过渡层使用简洁的状态语义，不向辅助技术暴露每个装饰图层。

## 7. 验证

- 主密码成功后播放一轮并进入主界面。
- 2FA 成功后播放一轮并进入主界面。
- 两种初始化完成方式均播放一轮。
- 密码或验证码失败时不播放动画。
- 锁定后重新登录会再次播放一轮。
- 连续状态更新不会创建多个时间轴或重复调用完成回调。
- 减少动态效果时显示完成帧后进入。
- 素材或动画初始化失败时直接进入，不停留在空白页。
- 在桌面和手机尺寸检查四框、锁块和最终 Logo 无裁切、重叠或横向滚动。
- TypeScript 检查和前端构建通过。

## 8. 完成标准

- 四种成功认证入口统一经过一次性动画。
- 动画期间不显示认证表单或账户主界面。
- 时间轴只播放一轮，最终 Logo 保持到自动进入主界面。
- 认证失败不触发动画，动画失败不阻塞成功认证。
- 正式应用不依赖外部 CDN。
- 锁定、再次登录和减少动态效果路径行为正确。
